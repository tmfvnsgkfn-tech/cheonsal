운영진 수정 방법

① 수정하기 선택 → ② GitHub 로그인 → ③ 내용 수정 → ④ Commit changes(변경사항 저장). 배포 완료 후 홈페이지에 반영됩니다. 권한이 없으면 저장할 수 없으며, 운영진의 GitHub 계정을 저장소 협업자로 초대해야 합니다.
