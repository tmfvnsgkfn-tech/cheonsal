천살의 첫 추억을 기다리는 중입니다.
🔐 관리자 사진 등록 / 삭제

사진은 천살 GitHub 저장소에 보관됩니다. GitHub 저장소에 수정 권한이 있는 계정만 사진을 추가하거나 삭제할 수 있습니다.

📤 사진 등록하기 (GitHub)🗑️ 사진 관리 / 삭제

사진 등록하기를 누른 후 파일을 선택하고, 맨 아래 Commit changes를 누르면 갤러리에 표시됩니다. 업로드 전 사진 파일명을 원하는 제목으로 바꾸면 해당 이름이 갤러리 제목으로 표시됩니다. 별도의 Firebase Storage 결제는 필요하지 않습니다.

주의: 이 방식은 갤러리 안에서 직접 업로드하는 것이 아니라 GitHub의 업로드 화면으로 이동합니다. 관리자 전용 권한은 GitHub 저장소 권한으로 관리합니다.

사진은 누구나 볼 수 있지만, 등록과 삭제는 저장소 수정 권한이 있는 사람만 가능합니다.
